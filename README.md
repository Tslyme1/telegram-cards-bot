# telegram-cards-bot

Простой Telegram-бот для группового чата: участники выдают друг другу
жёлтые карточки, за 6 жёлтых выдаётся красная, и участник с красной
карточкой мутится в чате на 30 секунд.

## Команды

- `/yellow [причина]` — ответом на сообщение участника выдаёт ему жёлтую
  карточку; причину указывать не обязательно, например `/yellow опоздал`.
  Раздавать карточки можно не чаще раза в 10 секунд (с одного аккаунта).
  На 6-й жёлтой карточке подряд участник получает красную, счётчик жёлтых
  сбрасывается, и бот пытается заглушить участника в чате на 30 секунд.
- `/cards` — список участников чата с количеством жёлтых и красных карточек.
- `/start`, `/help` — краткая справка.

Ограничения: карточку нельзя выдать себе или боту.

## Установка

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather) и получите токен.
2. Задайте переменную окружения `BOT_TOKEN` (см. `.env.example`):

   ```bash
   export BOT_TOKEN=123456:your-telegram-bot-token
   ```

3. Добавьте бота в нужный групповой чат.
4. **Обязательно** назначьте бота администратором чата с правом
   «Ограничивать участников» (Restrict members) — без этого бот не сможет
   мутить участников при получении красной карточки; сообщение о выдаче
   карточек и список работают без этого права.

## Запуск

```bash
python bot.py
```

Бот работает через long polling, отдельный сервер не требуется.

## Хранение данных

Счётчики карточек хранятся в SQLite-файле `cards.db` (путь можно
переопределить переменной `DB_PATH`), отдельно по каждому чату.
